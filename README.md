# hy345sh

Άσκηση 1 του μαθήματος Λειτουργικά Συστήματα (HY345) - υλοποίηση ενός απλού
κελύφους (shell) σε C.

## Τι κάνει

Το `hy345sh` διαβάζει εντολές από τον χρήστη και τις εκτελεί δημιουργώντας
διεργασίες-παιδιά (fork + execvp). Συγκεκριμένα υποστηρίζει:

- Prompt της μορφής `<ΑΜ>-hy345sh@<χρήστης>:<κατάλογος>`
- Πολλαπλές εντολές στην ίδια γραμμή, χωρισμένες με `;`
- Παγκόσμιες μεταβλητές (π.χ. `x=world` και μετά `echo $x`), υλοποιημένες
  πάνω στο environment με `setenv`/`getenv`
- Σωληνώσεις με `|` (πολλαπλές, π.χ. `ls | sort | uniq | wc`)
- Ανακατεύθυνση εισόδου/εξόδου με `<`, `>` και `>>`
- Συνδυασμούς όλων των παραπάνω, με ή χωρίς κενά ανάμεσα στα σύμβολα
  (π.χ. `ls -al>y1` δουλεύει το ίδιο καλά με `ls -al > y1`)
- Τιμές μεταβλητών με κενά ή ειδικούς χαρακτήρες μέσα σε εισαγωγικά, π.χ.
  `my_var="This is my var"` ή `x="5|5;10"` (τα `|` και `;` μέσα στα
  εισαγωγικά δεν λαμβάνονται υπόψιν σαν ειδικοί χαρακτήρες)

Βασικά builtins: `exit` για έξοδο από το κέλυφος, και η αναγνώριση των
αναθέσεων μεταβλητών (`name=value`), αφού αυτές δεν είναι πραγματικές
εξωτερικές εντολές.

## Compile & Run

```
make all
./hy345sh
```

Με `make clean` διαγράφεται το εκτελέσιμο.

## Πως δουλεύει (σύντομα)

1. `tokenize()`: παίρνει τη γραμμή εισόδου και τη σπάει σε tokens
   (λέξεις, `|`, `;`, `<`, `>`, `>>`), προσέχοντας τα εισαγωγικά ώστε ότι
   βρίσκεται μέσα σε αυτά να μένει ως έχει.
2. Τα tokens χωρίζονται σε "κομμάτια" με βάση το `;`. Κάθε κομμάτι είτε
   είναι μια ανάθεση μεταβλητής (`name=value`) είτε ένα pipeline εντολών.
3. `expand_variables()`: αντικαθιστά κάθε `$name` που βρίσκει μέσα σε ένα
   token με την τιμή του από το environment (`getenv`).
4. `execute_segment()`: σπάει το pipeline σε στάδια με βάση το `|`, φτιάχνει
   τα pipes ανάμεσά τους με `pipe()`, κάνει `fork()` για κάθε στάδιο και
   μέσα στο κάθε παιδί κάνει τα `dup2()` για stdin/stdout (pipes και
   ανακατευθύνσεις αρχείων) πριν καλέσει `execvp()`. Ο γονιός περιμένει
   όλα τα παιδιά με `waitpid()` πριν επιστρέψει στο prompt.

## Δοκιμές

Τρέχτηκαν όλα τα παραδείγματα εντολών από την εκφώνηση (age/pipes/redirect/
quotes/concat κ.λ.π.) και δίνουν τα αναμενόμενα αποτελέσματα.

Σημείωση: το πρόγραμμα φτιάχτηκε/δοκιμάστηκε τοπικά σε Linux (WSL), αλλά
θα πρέπει να τρέξει κανονικά και μέσα στο QEMU όπως ζητάει η εκφώνηση, αφού
χρησιμοποιεί μόνο standard POSIX κλήσεις (fork, pipe, dup2, execvp, wait).
